# 01_Foundations — how this folder is organised

Each module holds **two folders, one per era**:

| Folder | What's in it |
|---|---|
| `cohort2026/` | The **2026 cohort run** — this is where you work. `START_HERE.md` (session plan), `lessons/` (the written lessons + images), `notebooks/` (Alexey's lecture notebooks), `practice/` (your blank follow-along notebooks), the datasets, and the homework. |
| `solo_spring2026/` | The **solo run of Apr–Jun 2026**, frozen. Old homework, old notebooks, old datasets. Useful as a reference for *how* you did something — never for *what* the answer was: the 2026 cohort uses different data. |

Also here:
- `Geron_Ch02_California_Housing/` — book exercise, not a Zoomcamp module.

The clean, untouched copy of the whole course repo lives in
`00_Reference_Materials/mlzoomcamp-2026/` — don't work in there; `git pull` it for new material.
